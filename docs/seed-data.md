# Seed Data

Large data sets are generated by the `ELearning.Seeder` console app, not by API startup.

## Docker

```bash
docker compose run --rm seeder --profile small
docker compose run --rm seeder --profile medium
docker compose run --rm seeder --profile large
```

Reset only generated rows for a prefix before reseeding:

```bash
docker compose run --rm seeder --profile medium --reset-prefix
```

Use a separate generated data set:

```bash
docker compose run --rm seeder --profile large --prefix perf --reset-prefix
```

## Local

```bash
dotnet run --project src/ELearning.Seeder/ELearning.Seeder.csproj -- --profile small
```

Defaults:

- connection: `ConnectionStrings__DefaultConnection`, then local Postgres fallback
- prefix: `seed`
- password for generated users: `SeedPass123!`
- profiles: `small`, `medium`, `large`

The generated users use addresses like `seed.learner00001@seed.local`.
